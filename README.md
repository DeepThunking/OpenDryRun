# OpenDryRun

> A mobile-first web app designed for anyone who finds themselves unsheltered out in public. Built for instant access with **no app store downloads required**, it provides real, actionable alerts about predicted, current, and ongoing weather in their immediate area.

---

## Mission & Philosophy

**OpenDryRun** is a project under the **Deep Thunking** umbrella—a commitment to making open-source technology genuinely accessible, practical, and useful for everyday people. 

We believe that critical public utilities like real-time weather and safety alerts shouldn't be locked behind app store paywalls, forced software updates, or hardware requirements that exclude low-income or unhoused communities. Everyone carries a mobile browser; OpenDryRun meets them right there.

## What Makes It Actionable?

Weather data is only useful if it tells you what to do next. OpenDryRun is built to deliver real-time, high-utility situational awareness when you are caught out in the open:

* **Precipitation Tracking:** Real-time updates on when a rain or storm mass is about to hit your exact grid vector.
* **Immediate Shelter Direction:** Alerts designed to help you quickly identify nearby physical structures, overhangs, or transit canopies before the weather turns.
* **Low-Data Optimization:** Built lightweight so it works reliably even on limited data plans or unstable connections.

## Tech Stack

* **Backend:** Node.js / Express
* **Frontend:** Mobile-first Progressive Web App (PWA) architecture
* **Data Layer:** Open-source meteorological and geographic data sources
